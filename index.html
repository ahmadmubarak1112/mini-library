About

Mini Library was created by Ahmad Mubarak as a personal project to organize and manage my personal book collection at home.

The application includes features such as book search, category filtering, sorting, book detail views, favorites, dark mode, and a photo gallery.

This project was also built as part of my front-end development practice, with a focus on DOM manipulation, data filtering, sorting, local storage, and responsive interface design.

It was built using HTML, JavaScript, and Tailwind CSS version 4.3.3.
